Names are relative to the Django DIRS root that corresponds to the
edx-platform "lms/templates/" directory (see README "Open assumptions").

All templates use {% load i18n %} + {% blocktrans %} so a single packaged
file renders correctly under any active Django language/locale, the same
way upstream edx-platform templates do -- no per-language copies of these
files are needed. Per-language *admin-authored* content instead goes in
the EmailFamilyOverride registry model (models.py), which has an explicit
`language` column.

See docs/TEMPLATE_VARIABLES.md for which context variables are verified
against edx-platform source vs. inferred.
